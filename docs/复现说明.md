# 复现说明

## 输入与环境

使用课程授权提供的深圳房价 GeoJSON、地铁站点 GeoJSON、POI CSV、区级行政边界 GeoJSON 和出租车 CSV。相对位置独立复核还使用地铁线路及 OSMnx GraphML。所有压缩包先解压到 `data/raw/`，可保留子目录；该目录不纳入 Git。

`data/source_manifest.json` 保存原始压缩包的文件名、大小及 SHA-256，只作为输入指纹，不提供第三方数据下载。Python 3.11 与 `requirements.txt` 对应原实验版本；中文地图需本机存在中文字体，脚本会尝试 macOS 黑体或 Linux Noto CJK。

## 执行与结果

`python run_analysis.py --list` 显示完整执行顺序。`--task housing` 依次完成特征、基准、两方向空间验证、扩展模型与解释；`--task taxi` 完成质量检查、切段、停留、候选 OD、同车分区对照和地图。`--task all` 两者都执行。每步失败会停止并给出日志位置。

新结果默认在 `local_runs/results/`；公开历史汇总在 `分析结果/`。二者分开，以免把新的运行输出误当成历史实验快照。需要重新运行历史独立核验时，先在新的工作副本中生成完整实验结果，再将 `核查复核/` 与完整的 `分析结果/` 放在同一级，执行 `python 核查复核/复核实验.py /path/to/unpacked/data --part all`。该复核需要本地逐单元预测和事件明细，仅下载公开汇总不能执行全部复核。

## 时间与解释口径

房价标签为原空间单元 avgprice；输入不使用同批 minprice、maxprice。设施距离采用 EPSG:32650 的欧氏距离，POI 使用 1 km 邻域。空间五折分别按东向、北向坐标划分，训练侧设置 500 m 距离缓冲。

出租车仅有时分秒，无日期。默认假定每车时钟可比较，先在无效、同秒歧义、长间隔或异常位移处切段；不首尾环接。停留为距起始点不超过 200 m、跨度至少 300 s 的观测窗口。候选 OD 暂定状态 1 为载客，并对反向编码作对照。严格规则同时收紧切段和事件间隔。

这些规则能够被复现；缺日期和字典的真实语义不能靠重复执行恢复。公开检查的通过，也不代表客运方向或真实运营日已经得到确认。
